# 시험관 임신 일정표

폰과 PC 를 한 파일로 봅니다. 화면이 좁으면 표가 세로 카드로 펴지고, 넓으면 표 그대로 나옵니다.
이 폴더를 그대로 GitHub Pages 에 올리면 됩니다.

## 올리는 법

1. GitHub 에서 새 저장소를 만듭니다. 무료 계정은 공개 저장소여야 Pages 가 켜집니다.
2. 이 폴더가 그 저장소입니다. `index.html`, `.nojekyll`, `README.md`, `.gitignore` 가 들어 있습니다.
3. 저장소의 Settings 에서 Pages 로 들어가, Source 를 「Deploy from a branch」로 두고 Branch 를 `main` 과 `/ (root)` 로 고릅니다.
4. 1~2분 뒤 `https://chkimsu.github.io/ivf-timeline/` 로 열립니다.

## 알아 둘 것

- `index.html` 하나에 글, 모양, 그래프가 다 들어 있습니다. 바깥에서 불러오는 것이 없습니다.
- 검색에는 안 잡히게 해 두었습니다. 잡히게 하려면 `index.html` 머리의 `robots` 줄을 지우면 됩니다.
- `.nojekyll` 은 GitHub 가 파일을 손대지 않고 그대로 내보내게 하는 빈 파일입니다.
